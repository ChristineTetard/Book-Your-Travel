# Book-Your-Travel
Projet Bloc 1 – Application de réservation de voyages

## Description

Ce projet est réalisé dans le cadre du Bloc 1 - Développement Front-End.

L'objectif est de concevoir une interface web responsive permettant aux utilisateurs de consulter des services et d'effectuer une réservation en ligne.

Le projet met l'accent sur :
- la qualité de l'interface utilisateur ;
- la responsivité ;
- l'accessibilité (WCAG / RGAA) ;
- les bonnes pratiques HTML, CSS et JavaScript.

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Bootstrap (si utilisé)
- Git & GitHub

---

## Fonctionnalités

- Affichage des services
- Consultation des tarifs
- Calendrier de réservation
- Formulaire de réservation
- Interface responsive
- Navigation accessible (ARIA)
- Validation des formulaires

## Installation

1. Cloner le dépôt

```bash
git clone https://github.com/votre-utilisateur/reservation-services.git
```

2. Ouvrir le projet dans Visual Studio Code.

3. Lancer le fichier `index.html` avec Live Server ou dans un navigateur.
